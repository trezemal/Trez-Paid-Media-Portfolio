# Trez Malatesta | Google Ads and Paid Media

Personal portfolio site. Single self-contained page (`index.html`), no build step.

## Publish with GitHub Pages
1. Repo **Settings** > **Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`
3. Save. The site goes live at `https://<username>.github.io/<repo>/` in a minute or two.
